**徳島大学ゲームクリエイトプロジェクト** は、徳島大学の学生がチームを結成し、オリジナルゲームを制作する学生プロジェクトです。
企画・開発から作品の公開まで幅広く活動し、ゲームコンテストへの応募やイベントでの作品展示にも取り組んでいます。

なお、ゲームの開発には主に非公開リポジトリを使用しています。
